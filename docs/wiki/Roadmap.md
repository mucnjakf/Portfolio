# Roadmap

Nothing is scheduled at the moment. The ideas below came up in a review of the site and are kept here so they aren't lost.

## Ideas not planned yet

**Code**

- Self-host the Inter and Archivo fonts instead of loading them from Google Fonts, so no visitor data goes to a third party.
- Pause or slow down the dot grid when the pointer is idle, and skip the page-wide grid on touch screens, to save battery.
- Let blocks reveal only the first time they scroll into view (`once: true` in `ScrollReveal`).
- Give the company and school logos a fixed size and lazy loading, so the page doesn't shift while they load.
- Track the active navigation section with an `IntersectionObserver` instead of measuring every section on scroll.
- Render the page to HTML at build time, so search engines and previews that don't run JavaScript see the content.
- Turn on TypeScript's `strict` mode.

**Design**

- Rename "Contracts" to "Experience", the word recruiters look for.
- Add a closing contact section above the footer.
- Add a short case study for OrderPoint: the problem, the architecture and the key decisions, linking to its wiki.
- Explain what a blue (highlighted) skill means, or trim the skills list.
- Add the name, a back-to-top link and the navigation to the footer.
- Offer a "System" option next to light and dark.

What is deliberately left out is listed under [Scope](Scope).
