# <img src="portfolio.svg" width="50"/> Portfolio

### **👁️ Overview**
Personal Portfolio Web Application - 2026. 

<p align="justify">
    Portfolio is the personal website of Filip Mučnjak, live at <a href="https://mucnjakf.dev">mucnjakf.dev</a>. It is a single page that introduces Filip and the Minimalist studio he directs, and presents his projects, skills, contracts and education, with contact links and a downloadable resume. Projects come with showcase images, and with a carousel of slides when there is more to show. The site follows the visitor's light or dark theme, works on phones, tablets and desktops, and is built to be accessible. All content lives in JSON files, and the static build is published to GitHub Pages.
</p>
